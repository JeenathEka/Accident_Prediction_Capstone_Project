# Accident Prediction Capstone Project

Use streamlit + ML + LLM to Forecasting Predictive Regional Accident 

This project divided into 4 parts 

part1 -> Feature Engineering (data cleaning)
part2 -> Model selection Finding suitable ML model
part3 -> LLM calling
part4 -> streamlit app for front end 


Each part contains seperate README.md file which explain what it do.

-----------------------
How to run this project ?

    Execute following command:
        python -m venv .venv  -> create environment   
        .\.venv\Scripts\activate -> activate environment
        pip install -r req.txt -> install all dependency


    Run:
        paste your "OPENROUTER_API_KEY" in .env
        go to part4 
        streamlit run .\app.py   -> run this command stream lit application will up and run
